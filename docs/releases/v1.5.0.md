# 编程练习册 v1.5.0

面向初学者的**本地编程练习与判题工具**，第一个正式发布的版本 🎉

写代码 → 点「运行并判题」→ 立刻知道自己错在哪，错的地方它会告诉你往哪个方向查。

## 本版更新

**新增**

- **自动检查更新**：启动时自动看看有没有新版本。有的话弹窗告诉你是哪个版本、改了些什么，点「去下载」直接跳到对应的安装包。可以在「设置 → 关于」里关掉，也可以只跳过某一个版本。

**修复**

- 深色模式下，判题结果的说明文字是**黑色**的 —— 压在深色背景上几乎看不见。
- 浅色模式下，「交互终端」输入框里敲的字看不见（输入框底色和文字色撞在一起了）。

**变化**

- **指针 / 引用题现在会检查你是不是真的用上了它。** 以前只比对输出，`int b = n;` 和 `*p` 打出来一模一样，不用指针也能判过 —— 这显然不符合出题的用意。现在这类题会额外核对源码：判不过时它会先说清「你的输出是对的，但这题要练的语法还没用上」，再告诉你具体该怎么改。如果你确信自己的写法没问题，可以在「设置 → 判题」里关掉这项检查。

## 应用里有什么

- **三门语言**：Python、C、C++，各自独立 —— 题库、进度、错题、收藏、测试历史、成就都分开统计，顶栏一键切换
- **每门 72 题，一共 216 题**：12 个分类从基础语法一路到综合挑战，难度分简单 / 中等 / 困难
- **每题都有教程**：像文档一样分节讲解，边看边练，不是丢一道题让你自己悟
- **不会的能问**：多级提示逐步给方向；实在不行可以看参考代码，注释里写的是思路和易错点，不是复述代码
- **判题给方向，不只会说「错了」**：程序崩了会提醒你查数组越界和指针，整数除以 0 会单独指出来，编译器报错会翻译成人话
- **交互式运行**：能一行一行喂输入，亲眼看到每次 `input()` / `scanf` 各读走了哪一行 —— 这是很多人卡住的地方
- **错题本、收藏、测试模式、进度统计、成就称号**；进度可以导出备份

## 下载哪个

- **Windows** — `编程练习册-Setup.exe`
  双击安装。**不需要管理员权限**，装在自己的用户目录里。
- **macOS** — `编程练习册-macOS-universal.dmg`
  打开后把图标拖进「应用程序」。Intel 和 Apple Silicon 机器都能用（同一个包）。
- **Linux** — `编程练习册-linux-x86_64.tar.gz`
  解压即用，压缩包里附了 `.desktop` 文件。

Windows 和 macOS 还多打了一份免安装的 zip 绿色版，解压就能跑；Linux 的 tar.gz 本身就是解压即用。

## 第一次打开会被系统拦一下

这不是应用有问题，是因为没有买代码签名证书（Apple 那边 $99/年）—— 个人开发的小工具都会遇到这一步：

- **macOS** 提示「来自身份不明的开发者」：
  **右键点应用图标 → 选「打开」→ 再在弹窗里点一次「打开」**。之后就不会再问了。
- **Windows** 提示「Windows 已保护你的电脑」：
  点「**更多信息**」→ 再点「**仍要运行**」。

## 运行环境

- **Python**：macOS 和 Windows 版已经内置解释器，装完就能用；Linux 用系统自带的 `python3`
- **C / C++**：需要本机有编译器（clang / gcc / MinGW）
  - 第一次打开会有一个**设置向导**帮你把三门语言的环境都检查一遍
  - Windows 上可以在向导里**一键安装 MinGW**，不用自己去官网翻下载页

缺什么不用猜：「设置 → 代码编辑」里会写明现在实际用的是哪个路径；缺的话直接给对应平台的安装命令。

## 关于联网

**判题全部在你自己的电脑上完成，不联网、不用注册**，代码和进度都不会传出去。

唯一会联网的地方是启动时查一下有没有新版本（就是本版新增的那个功能）。不想让它查，在「设置 → 关于」里关掉即可。
