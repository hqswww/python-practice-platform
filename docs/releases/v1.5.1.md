# 编程练习册 v1.5.1

## 本版更新

**新增**

- **测试可以限定出题范围了**：四种测试模式（快速 / 标准 / 强化 / 全题库）**各自**设定从哪些大类出题、出到哪个难度。难度按颜色分档 —— 🟢 难度一（只出简单）、🟡🟢 难度二（加中等）、🔴🟡🟢 难度三（全部）。范围内没有困难题时，「难度三」会自动变成不可选。
- 抽题改成**按难度比例**出：每次卷子的难度结构都一样，不会这次全简单、下次连出三道难题。

**改进**

- 测试页排版重排：每个模式一张卡片（模式名、题量、两个设置、开始按钮各就各位），宽窗口摆成 2×2，一眼能扫完。

**修复**

- 一个挺要紧的问题：**测试抽题没有按当前语言过滤**。之前「全题库」显示 216 题（三门语言混着算），一次 Python 测验里会混进 C 和 C++ 的题。现在只出当前语言的题，题池也回到 72 题。
